Zeno-Micro-PC

Zeno Micro PC is a lightweight, adaptive computing platform designed for the ESP32 series. It runs on Zeno OS, a fully hardware-adaptive operating system featuring a priority-based task scheduler, custom adaptive firmware, custom CLI, and a custom GUI rendering engine.

The platform comes with a robust suite of built-in applications:

1)ZenApp Store
2)Image Viewer
3)File Manager
4)Calculator
5)Notepad
6)System Settings
7)System Updater
8)Task Scheduler
9)MicroPython Interpreter
10)ZenCMD

Zeno Micro PC is designed to be developer-friendly, offering a platform for testing and running applications directly on the device. Users can install, run, and manage multiple applications without ever reflashing the ESP32 board, thanks to the ZenApp Store, where apps can be uploaded, downloaded, installed, and developed entirely on-device.

The device also serves as an educational platform, allowing users to explore operating system frameworks, learn app development, and experiment with IoT projects. In the future, it will integrate with TinyML modules to provide basic AI capabilities and further expand its learning and development potential.

Zeno Micro PC supports a 2.8-inch touchscreen display, SD cards up to 32GB, and full Wi-Fi/Bluetooth connectivity, making it a standalone, fully capable computational device suitable for both developers and learners alike.
